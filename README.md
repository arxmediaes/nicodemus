# Salvemos A Nicodemus — GitHub Pages

Sitio estático reconstruido a partir del contenido recuperado de la versión publicada el 8 de octubre de 2026. **No es una copia exacta del código fuente original de ChatGPT Sites.**

## Publicación

Sube `index.html` a la raíz del repositorio. En GitHub → Settings → Pages selecciona Deploy from a branch → main → / (root).

En Cloudflare Pages, usa el repositorio con Framework preset: None, build command vacío y output directory `/` (o despliegue de archivos estáticos).

## Antes de publicación definitiva

- Reemplazar fondos gráficos por banner/fotografía oficial de la banda. El original no estaba disponible para exportar.
- Sustituir enlaces de búsqueda de YouTube, Spotify y Apple Music por enlaces directos oficiales.
- Confirmar Instagram, TikTok y la vía de contrataciones; el enlace actual de Instagram es genérico.
- El sitio no necesita npm, Vite ni dependencias de build.
